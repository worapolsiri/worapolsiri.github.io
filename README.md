# worapolsiri.github.io

Personal portfolio site — single page, static HTML/CSS, no build step.

## Structure
```
index.html
assets/
  photo.jpg
  Worapol-Siriburi-CV.pdf
```

## Deploy on GitHub Pages
1. Replace the contents of your `worapolsiri.github.io` repo with these files
   (keep `index.html` at the repo root, and the `assets/` folder alongside it).
2. Commit and push to the `main` branch.
3. In the repo, go to **Settings → Pages**, and under "Build and deployment"
   set Source to **Deploy from a branch**, branch **main**, folder **/(root)**.
4. Your site will be live at `https://worapolsiri.github.io/` within a minute or two.

## Updating content later
Everything lives in `index.html` — text, timeline entries, skills, and links
are plain HTML, no templating. To swap the photo or résumé, replace the files
in `assets/` and keep the same filenames (or update the `src`/`href` in
`index.html` if you rename them).
